# User guide

For musicians and producers working inside Gloopy. If you're driving Gloopy from
code instead, use [Control & scripting](../control-scripting/index.md).

## Start here

Need to get Gloopy first? See [Install Gloopy](install.md). New to it? Do the
tutorial:

[:material-play: Your first track](tutorials/first-track.md){ .md-button .md-button--primary }
[:material-download: Install Gloopy](install.md){ .md-button }

Not sure which feature to reach for? **[What to use for what](what-to-use-for-what.md)**
is the quick decision guide — Arrange vs. Session, Save vs. Export, Automation vs.
Modulation, and the other look-alike choices.

## This section

Following the [Diátaxis](https://diataxis.fr/) split, pages here come in four kinds:

- **[Tutorials](tutorials/first-track.md)** — hand-held lessons that build a
  skill from zero. Start with *Your first track*.
- **[How-to guides](how-to/index.md)** — recipes for one real task each
  (recording, arranging, mixing, exporting).
- **[Explanation](explanation/index.md)** — how Gloopy thinks: the arrangement
  vs. the session, gain staging, the musical model.
- **[Reference](reference/index.md)** — menus, keyboard shortcuts, and settings,
  looked up quickly.

## The vocabulary

*Track*, *clip*, *scene*, *transport*, *mixer track* — all defined once in
[**The Gloopy model**](../control-scripting/concepts/model.md). It lives on the
developer side of the manual but is written for everyone; when a term is unclear,
that's the page to check.
